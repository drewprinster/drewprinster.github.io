{%- comment -%} Renders a publication's author list, bolding the site owner. Matching is by substring so an equal-contribution marker (e.g. "Drew Prinster*") still highlights correctly. Falls back to the `citation` string if no structured `authors` list is present. Usage: {% include author-list.html publication=post %} {%- endcomment -%} {%- assign me = site.data.profile.name | default: site.name -%} {%- assign pub = include.publication -%} {%- if pub.authors and pub.authors.size > 0 -%}
{%- for author in pub.authors -%} {%- if author contains me -%} {{ author }} {%- else -%} {{ author }} {%- endif -%} {%- unless forloop.last %}, {% endunless -%} {%- endfor -%}
{%- if pub.author_notes %} {{ pub.author_notes }} {%- endif -%} {%- endif -%}
